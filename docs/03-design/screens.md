# Screen Inventory

Source: MaxBid Project Workbook, tab 16 Screens.

| ID | Screen | Purpose | Key components | Device |
| --- | --- | --- | --- | --- |
| SC01 | Sign in | Access | Magic link, Google sign in | Both |
| SC02 | Dashboard | Recent analyses, watchlist closing soon, credit balance | Analysis cards, closing countdown list, credit meter | Desktop first |
| SC03 | New analysis | Submit URL or PDF and choose cost profile | URL field with platform detection, PDF drop zone, profile selector, triage allowance note | Both |
| SC04 | Analysis progress | Show extraction and triage progress | Stage stepper, progress bar, leave page notice | Both |
| SC05 | Triage table | Rank and shortlist lots | Dense table, opportunity score, rough range, rough max bid, filters, checkbox shortlist, credit preview bar | Desktop first |
| SC06 | Lot detail | Deep analysis result for one lot | Photo strip, identification card with confirm and edit, valuation band, confidence badge, bid limits, calculator | Desktop first |
| SC06A | Spec sheet section | Enriched specifications for the lot | Four source class groups, optional equipment checklist, conflict flags, source links, Report a problem, download PDF | Desktop first |
| SC07 | Evidence panel | Show comparables | Comparable rows with match level badge, reason, differences, price, date checked, link, exclude toggle | Desktop first |
| SC08 | Calculator panel | Costs and profit | Collapsed cost summary with expand, profit mode toggle, bid slider with green, amber and red zones, cash required and effective cost | Both |
| SC09 | Watchlist | Track lots across auctions | List with countdown, target and absolute maximum, alert settings | Both |
| SC10 | Mobile bid view | Use while bidding | One lot per card, very large target and maximum figures, stop line, swipe between lots | Mobile |
| SC11 | Outcomes | Record results | Quick won or lost entry, hammer price, resale price later, accuracy indicator | Both |
| SC12 | Cost profiles | Manage defaults | Profile list, editor for each cost line and transport rate | Desktop first |
| SC13 | Settings | Organisation, GST, base location, members, alerts | Forms, member invite, role selector | Desktop first |
| SC14 | Billing (phase 2) | Plan and credits | Plan cards, credit history, top up purchase | Desktop first |
| SC15 | Admin | Platform health and costs | Extractor status, premium defaults, category rules, cost per job charts | Desktop |
| SC16 | Onboarding | Three step setup and guided first analysis | GST toggle with plain explanation, base location, profit target, sample catalogue option, progress indicator | Both |
| SC17 | Try before sign up result | Sample triage for anonymous visitors | Top lots from a cached triage, blurred remainder, sign up call to action, DS21 note | Both |
